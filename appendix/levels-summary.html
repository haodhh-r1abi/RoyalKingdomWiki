Default (N.bytes, name suffix _E) vs ThreeColor (c_N.bytes, suffix _F)

LevelListExtensions.GetByteFilePrefix: LevelList.Default → no prefix, LevelList.ThreeColor → c_, LevelList.Reactivation → reactivation_. LevelResolver / RLevelType (remote) pick the list per player.

  • Average moves: Default 26.5, ThreeColor 18.7.
  • ThreeColor levels with 3 colours: 5407/5600; with IsLowMatch: 4793/5600.
  • Same moves+goals+features as the Default copy: 771; moves differ: 4828; goals differ: 16.
