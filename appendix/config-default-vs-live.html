Config mặc định vs live

Config mặc định (Resources) so với config live (snapshot 11/11/2026) · nguồn appendix/config-default-vs-live.md

So từng khoá giữa JSON mặc định đóng gói trong client (Assets/Resources/*.json, xem default-configs.md) và bản server đã cache trong snapshot facts/runtime/live_1111/app_pFiles (DB App và U_<id>; tài khoản mới, level thấp, Việt Nam). Trạng thái: bằng (giá trị trùng), đổi (mặc định → live), chỉ live (khoá chỉ có ở bản server), chỉ mặc định (khoá chỉ có trong JSON đóng gói). Trước khi so, chuỗi số ("a":"1") được đổi sang số và trường tên rỗng "n":"" được bỏ qua (bản server luôn gửi n rỗng, bản mặc định bỏ trống). Bảng diễn giải ban đầu được biên soạn từ scratchpad. Nay có tools/rk_snapshot_audit.py tái sinh đối chiếu mọi leaf của 8 cặp nguồn; xem config-leaf-diff. Hai loại bảng có đơn vị đếm khác nhau (nấc và leaf), không đồng nhất số đếm.

Cách client chọn nguồn: AEventDataHelper.LoadConfig đọc config User/Server đã lưu, rỗng thì nạp JSON mặc định (BlitzManager.TryLoadLocalDefaultConfig, FeatureDependencyManager.LoadConfig với ConfigVersion = 0, AdManager.LoadActiveConfigRules). Vì vậy JSON mặc định chỉ chạy khi server chưa trả lời (offline lần đầu) — mọi khác biệt dưới đây là phần server đang chỉnh so với bản dự phòng.
