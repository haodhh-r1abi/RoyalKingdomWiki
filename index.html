Tổng quan sự kiện
LiveopsEventType → manager, level mở khoá, config class, JSON mặc định, số lệnh backend.

Level mở khoá
Hằng số *UnlockLevel* trong client, sắp theo level.
🎁
Mã phần thưởng
Mã thưởng trong config/server (C, UL, H, CP2…) → RewardType, kèm icon.
💳
Sản phẩm IAP
55 product id và giá USD mặc định trong client.
🧩
Level & thống kê
5.600 level chính + 5.600 ThreeColor: lượt đi, mục tiêu, level tấn công; bảng toàn bộ level.
🧾
Config mặc định trong APK
29 file Resources/*.json làm phẳng thành path = value.
🔌
Giao thức backend
Bảng FlatBuffers request/response/Info và enum backend.
🔢
Enum
RewardType, ItemType, BoosterType, LiveopsEventType… đọc từ metadata IL2CPP.
🧮
Mảng tĩnh (metadata)
Mảng khởi tạo tĩnh giải từ global-metadata.dat, theo method dùng.
🔤
Text UI (EN)
Term I2 Localization và câu tiếng Anh; 28 ngôn ngữ trong file tải về.
💾
Trạng thái lưu (save)
Bảng/khoá trong SQLite App và U_<id> của snapshot 11/11 (đã che ID).
