Mô tả

  • Mọi sự kiện live-ops (31 LiveopsEventType) dùng chung một khung: AEventManager quyết định đủ level (hằng số UnlockLevel riêng), nhóm AB, kill switch server và việc bị FeatureDependency chặn; AEventDataHelper nạp config có version từ server (User/Server) hoặc JSON mặc định; các dialog tự động bắt đầu/nhận thưởng/thông tin chạy theo luồng Home; tiến trình gửi kèm cuối level và Ping.
  • EventRewardOverrider cho phép 4 sự kiện 'chèn' (Card Collection, Pearls of Atlantis, Hidden Path, Blitz) thêm phần thưởng của mình vào bảng thưởng của sự kiện khác theo biến thể RewardOverrideEventType (40 biến thể, kể cả các kiểu pass), khi thời gian hai sự kiện chồng nhau.
  • Phần UI dùng chung: Events tab (từ level 200), pass free/gold và co-op, dialog tham gia từ chat, dialog hết vật phẩm thu thập.

Tóm tắt thiết kế

Code Cả 31 LiveopsEventType chạy trên một lớp nền AEventManager. Icon chỉ hiện khi qua đủ 4 cổng: level ≥ UnlockLevel (hằng số trong client), nhóm AB, kill switch (một bit trong GameSettings.Flags) và FeatureDependency cho phép, cộng thêm điều kiện bundle đã tải.

CodeAPK Config đi theo phiên bản: server gửi {EventId, EndDate, ConfigVersion, Config}. Client giữ bản Server (chung) và bản User (chụp lại lúc người chơi vào kỳ); thiếu thì dùng JSON mặc định trong Resources. Bundle của event được tải trước khoảng 5 level so với level mở (ví dụ Kingdom Pass tải ở 26, mở ở 31).

Code Mọi event tính điểm thắng màn từ một hệ số chung GetMultiplierForLevel: thường 1, Hard 2, Super Hard 5, Kingdom 3, Dark 10, Richard's Journey 2 (đặc biệt chỉ từ level 25), rồi nhân Magic Pot. Vì vậy một màn khó tăng điểm ở mọi event cùng lúc.

CodeAPKLive 11/11 Chèn thưởng: 4 event (Card Collection, Pearls of Atlantis, Hidden Path, Blitz) thêm vật phẩm của mình vào bảng thưởng của event khác (40 biến thể bảng), với điều kiện event chèn bắt đầu trước khi event kia kết thúc ít nhất 2 phút và kết thúc sau nó. Live 11/11: Card Collection chèn gói thẻ vào 39 bảng.

Code Dialog tự động ở Home xếp theo thứ tự nhận thưởng → bắt đầu → thông tin, chỉ khi đã vào màn chơi ít nhất 1 lần trong phiên. Popup nhắc chỉ hiện sau hơn 4 lần vào màn. Events Tab (thẻ 2 cột) mở từ level 200 nếu config có eventTab (live 11/11: tắt).

Luồng người chơi từng bước

  1. Gửi event infoServerCode
    Qua Get<Event>EventInfo, Refresh hoặc Ping. AEventDataHelper.UpdateConfig chỉ nạp khi version mới (ShouldUpdateConfig). Chưa có config thì log “LoadDefaultConfig as {0}Config” và dùng TextAsset trong Resources.
  2. Tải trước bundleClientAPK
    *_bundle_config.json đặt level bắt đầu tải bundle, đa số bằng level mở − 5 (Cube Blast 36, Magic Carnival 46, Hill/Canvas/Weekly 96, Medal Missions 141, Events Tab 195). Event có ngôn ngữ riêng thì đăng ký thêm I2 LanguageSource từ bundle.
  3. Kiểm tra 4 cổngClientCode
    ShouldShowIcon = HasEnoughLevel và không bị AB loại (NewUserAbId / OldUserAbId) và không bị kill switch (IsBitSet(flags, DisabledBit)) và không bị FeatureDependency chặn. Qua hết thì TryCreateIconView dựng icon từ bundle (trái/phải Home, prelevel).
  4. Vừa đạt level mởClientCode
    EventsHelper.ArrangeStateAfterUnlockLevel duyệt các event vừa đủ level, gọi lại event info, nên event hiện ngay sau trận mở khoá.
  5. Dialog tự độngGiao diệnCode
    Ở Launch / FocusIn / ForceHomeScene / LevelFail: TryAddAutoDialog xếp claim → start → info nếu CanShowAutoPopup (đã vào màn ≥ 1 lần, không có bot). Popup nhắc cần GameSceneLoadCount > 4. Deeplink của event cũng đi qua cùng luồng.
  6. Chơi mànClientCode
    Hook OnLevelStart / Win / Fail ghi dữ liệu. AddRewardDatas lấy hệ số chung rồi mỗi event cộng theo luật riêng. Lệnh cập nhật đi kèm level-end hoặc Ping (AppendCommandsToLevelEndOrPing), thử lại tối đa 3 lần. Bỏ màn giữa chừng có thể hiện cảnh báo mất tiến độ event.
  7. Dựng bảng thưởng (chèn thưởng)ClientCode
    GetOverridenEventStep → EventRewardOverrider hỏi lần lượt Card Collection → Pearls of Atlantis → Hidden Path → Blitz. Nếu có bảng chèn cho biến thể RewardOverrideEventType và thời gian hợp lệ thì MergeReward (cùng mã thì cộng dồn, khác mã thì thêm). Rương quận Kingdom, Kingdom Pass và pass co-op có đường chèn riêng.
  8. Events TabGiao diệnCodeLive 11/11
    Level ≥ 200 và config có eventTab: lưới thẻ 2 cột, trạng thái Upcoming / ReadyToStart / InProgress / Open / Completed. Tutorial cuộn chỉ chạy khi có ≥ 5 event active, highlight 3 s. Live 11/11: tắt.
  9. Hết giờClientCode
    OnEventTimeFinished → FeatureDependency đưa icon khác vào slot. Thưởng chưa nhận thì claim dialog ở lần vào Home sau. Pass ở trạng thái FinishedWithUnclaimedSteps thì tự nhận (ClaimUnclaimedPassSteps).
  10. Kill switchServerCode
    Bật bit trong GameSettings.Flags thì event biến mất ngay (OnDisabledByBackend) và các mission task đã tạo từ event này bị huỷ.
  11. Người chơi đã hết 5.600 levelClientCode
    Island Race, Power Rush, Dungeon Escape, Gem Hunt, Kingdom Duels hỏi ArenaManager: chỉ vào được khi có arena đang mở (Island Race cần arena còn > 15 phút).

  1. Server gửi event info (EventId, EndDate, ConfigVersion, Config) qua Get*EventInfo, Refresh hoặc Ping; AEventDataHelper lưu config Server (chung) và User (sau khi vào), thiếu thì nạp JSON mặc định trong Resources.
  2. Mỗi lần Home kiểm tra icon, manager phải đủ level, không bị AB loại, không bị kill switch (bit của GameSettings.Flags) và được FeatureDependency cho hiển thị; khi đó TryCreateIconView tạo icon từ bundle của sự kiện.
  3. Lúc vào Home (Launch/FocusIn/ForceHomeScene/LevelFail) TryAddAutoDialog xếp dialog nhận thưởng → bắt đầu → thông tin nếu CanShowAutoPopup (đã vào game scene ít nhất 1 lần, không có bot), popup nhắc chỉ khi đã vào màn chơi > 4 lần.
  4. Khi chơi, các hook OnLevelStart/Win/Fail ghi dữ liệu và AppendCommandsToLevelEndOrPing gửi lên server (thử lại tối đa 3).
  5. Bảng thưởng của sự kiện được dựng qua GetOverridenEventStep: EventRewardOverrider hỏi Card Collection, Pearls of Atlantis, Hidden Path, Blitz xem có bảng chèn cho RewardOverrideEventType tương ứng không và thời gian có chồng nhau không, rồi MergeReward.
  6. Hết giờ: OnEventTimeFinished, FeatureDependency thế icon khác, phần thưởng/pass chưa nhận được tự nhận hoặc qua dialog claim.
  7. Server có thể tắt từng sự kiện tức thì; khi đó mission task của sự kiện bị hủy.
