Mô tả

  • Home là kingdom 3D có lớp UI: thanh trên (mạng, coin, potion, profile, Settings), thanh dưới với các section (Shop, Leaderboard, Home, Team và một section thứ năm thuộc Card Collection hoặc Medal Missions), cột icon event hai bên, nút Play, Tasks, World, Events tab.
  • Mỗi lần vào Home (mở app, thắng, thua) HomeSceneFlow dựng một hàng đợi hành động (FlowManager): nhận thưởng đang chờ, popup đánh giá, hộp thư, tutorial, dialog bắt đầu event, offer, nhắc nhở và hoạt ảnh icon — theo thứ tự cố định để không chồng dialog.
  • DialogManager giữ chồng dialog, chỉ một dialog không toàn màn hình hiện một lúc, nút Back đóng dialog trên cùng hoặc hỏi thoát game.
  • SceneController chuyển giữa Start / Home / Game và có thể preload scene.

Tóm tắt thiết kế

Code Home là vương quốc 3D (tab Map) phủ một lớp UI: thanh trên (mạng, coin, potion, profile, Settings), thanh dưới 5 section (Shop −2, Leaderboard −1, Home 0, Team 1, section thứ năm thuộc Card Collection hoặc Medal Missions), hai cột icon event, các nút Play, Tasks, World. Vương quốc chỉ render và nhận chạm khi đang ở tab Map.

Code Mọi popup tự mở đi qua FlowManager với thứ tự cứng theo lý do vào Home: mở app (17 bước), thắng level (16 bước), thua level (ít hơn: không claim, không dialog bắt đầu event). DialogManager chỉ cho 1 dialog không toàn màn hình mỗi lúc; nút Back đóng dialog trên cùng hoặc hỏi “Quit Game?”.

Code Sau trận thắng: hoạt ảnh thưởng → Rate Us → hộp thư → No Ads → nhận thưởng 22 event đã kết thúc (Card Collection, Arena, Kingdom Pass…) → tutorial → dialog bắt đầu 23 event → dialog offer (Welcome Pack, Ladder Offer, Mythic Deal, Coin Craze) → nhắc nhở → mạng xã hội. Rate Us đứng ngay sau hoạt ảnh thưởng, đúng lúc người chơi vui nhất.

Live 11/11 Cột icon (FeatureDependencyConfig v206): mỗi cột tối đa 5 icon, chọn từ 7 nhóm loại trừ; cột trái là event, cột phải là pass/offer/mission (chi tiết ở trang FeatureDependency).

Nhận định Không thấy hằng số giới hạn số popup mỗi lần vào Home (khác Block Out: 3 đầu phiên / 2 sau trận). Royal Kingdom dựa vào thứ tự cứng và trạng thái auto-dialog của từng event (New 0, Info 1, Entered 2, Finished 3) để mỗi trạng thái chỉ hiện một lần.

Luồng người chơi từng bước

  1. Chuẩn bị vào HomeClientCode
    HomeSceneFlow.ArrangeFlow tắt xoay và chạm, ẩn thanh trên/dưới để chuẩn bị hoạt ảnh; StartFlow chạy HomeUi.PlayAppearAnimation rồi rẽ nhánh theo lý do: launch, thắng, thua, quay lại app (OnFocusIn), bị ép về Home.
  2. Mở appGiao diệnCode
    17 bước (bảng 1): chỉnh giờ → thử lại giao dịch dở → hộp thư → No Ads → quà mốc nghìn còn nợ → Welcome Back → Daily Refill → ghi đăng nhập → … → auto-dialog → tooltip Weekly Contest → thưởng like/follow. Nếu phải ép tutorial profile thì client nhận thưởng icon không hoạt ảnh và bỏ phần auto-dialog của lần đó.
  3. Về Home sau thắngGiao diệnCode
    16 bước (bảng 2), bắt đầu bằng PushLevelWinRewardAnimationAction (coin, sao, potion bay về thanh trên), rồi Rate Us và chuỗi claim / start dialog / offer.
  4. Về Home sau thuaGiao diệnCode
    Chỉnh giờ → hộp thư → ghi đăng nhập → hoạt ảnh icon dạng thua → tutorial Richard's Journey → No Ads → tutorial Weekly Contest → tutorial tab Events → Card Collection → thử lại giao dịch → auto-dialog.
  5. Hàng đợi hành độngClientCode
    MainFlowExecutor giữ 5 danh sách: chính, auto, next (PushToNext chèn ngay sau action đang chạy), inner flow (chuỗi con trong một dialog) và auto trễ. Auto-dialog tạm dừng khi rời tab Home; đổi scene thì xoá hàng đợi ('MainFlow cleared! {0}').
  6. Đổi sectionNgười chơiCode
    SectionManager.RequestSection → trượt sang Shop / Leaderboard / Home / Team / section thứ năm; bấm lại section đang mở gọi OnSectionReClicked. Quà Daily Refill, Welcome Back… chờ tới khi người chơi về tab Home mới hiện.
  7. Dialog và nút BackGiao diệnCode
    DialogManager.ShowDialog: đang có dialog không toàn màn hình thì đóng/ẩn nó ('There is already a not fullscreen dialog!'). Nút Back: đóng dialog trên cùng nếu cho phép, không còn dialog thì ApplicationQuitDialog “Quit Game? Are you sure you want to quit?”; trong level là “Quit Level? You will lose a life!”.
  8. Tooltip và bảng thưởngGiao diệnCode
    Chạm icon / phần thưởng mở tooltip động (LoadDynamicRewardTooltip); thưởng ngẫu nhiên có nút 'Learn More' sang trang công bố xác suất. RewardPanel hiện gói thưởng, card pack, wild card.
  9. Chế độ Arena và chế độ xâyClientCode
    HomeUi.SetArenaUi đổi skin UI sang Arena (bundle liveops/arena/arena_homeui). Bấm Tasks: PrepareHomeUiForBuildState ẩn bớt UI và chạy hoạt ảnh vào build state; có task mới thì nút Tasks có hiệu ứng 'NewTasksButtonParticles'.
  10. Chuyển sceneClientCodeLive 11/11
    SceneController chuyển Start / Home / Game, preload scene kế tiếp trừ khi PreloadSceneDisabled (live 11/11 = 0). Đổi user hoặc refresh tiến trình thì ForceLoadHomeSceneWhenPossible.
  11. Playtest 12/11/2026 — bằng chứng quan sáttesterPlaytest
    Các ảnh sau đã quan sát trên LDPlayer. Ngoại trừ Richard’s Journey ở level1, các case dùng override local Level=151. Chưa bao phủ mọi nhánh win/fail/claim/end/AB; xem nhật ký và ma trận case.

Vận dụng cho game khác

  • Đặt mọi popup tự mở vào một hàng đợi có thứ tự cứng theo lý do vào Home (mở app / thắng / thua). Dễ debug, không bao giờ chồng dialog.
  • Sau trận thắng, cho phản hồi trực tiếp của trận (thưởng bay về) và Rate Us lên đầu, rồi mới tới claim event và quảng bá event mới.
  • Sau trận thua, cắt bớt: không claim, không dialog bắt đầu event, chỉ những thứ giúp người chơi quay lại (tutorial, nhắc No Ads, auto-dialog).
  • Nhận định Rủi ro: không có trần số popup, một lần thắng có thể kéo theo nhiều dialog liên tiếp khi nhiều event cùng kết thúc. Nên đo số dialog trung bình mỗi lần về Home, và nếu cần thì thêm trần như Block Out (2–3).

  • Đổi section: Thanh dưới đang ở Shop hoặc Team
  • Dialog và nút Back: ApplicationQuitDialog 'Quit Game?' khi bấm Back

Mở khóa & điểm vào

Có từ khi về Home lần đầu (sau level đầu). Section thứ năm chỉ hiện khi Card Collection hoặc Medal Missions sở hữu (FifthSection.ResolveOwner). Icon event phụ thuộc FeatureDependencyConfig (xem FeatureDependency).

Điểm vào:

  • Mở app → Home (StartFlowAfterLaunch)
  • Thắng level → Home (StartLevelWinFlow)
  • Thua / thoát level → Home (StartLevelFailFlow)
  • Quay lại app (OnFocusIn → StartFlowAfterFocusIn)
  • Bị ép về Home (StartFlowAfterForceHomeScene)
  • Nút Back Android (DialogManager.PressBack)

Cách hoạt động

  1. HomeSceneFlow.ArrangeFlow tắt xoay và chạm, ẩn thanh trên/dưới để chuẩn bị hoạt ảnh; StartFlow(playAppearAnimation) chạy HomeUi.PlayAppearAnimation và nhánh theo lý do vào Home.
  2. Mở app (StartFlowAfterLaunch): DailyLogin phát hiện chỉnh giờ → thử lại mua chưa xong (PurchaseManager.ShowRetryPurchaseDialogIfNeeded) → hộp thư hệ thống → nhắc No Ads → nhận thưởng mốc 1000 level còn nợ (ShowNThousandLevelRewardsAction.TryAddClaim) → quà Welcome Back → Daily Gift → ghi đăng nhập DailyLogin → Card Collection hoàn tất → thưởng pass còn nợ của Pearls of Atlantis / Hidden Path → thưởng task còn nợ Medal Missions → tutorial Home → tutorial profile (bắt buộc) → hoạt ảnh icon → auto-dialog → tooltip Weekly Contest → thưởng like mạng xã hội.
  3. Thắng level (StartLevelWinFlow): hoạt ảnh thưởng thắng → review store / RateUs → hộp thư → No Ads → TryAddClaims → dialog migrate Attack cũ → DailyLogin → hoạt ảnh icon → tutorial → dialog bắt đầu event → dialog bắt đầu offer → nhắc nhở → dialog cuối level khác → mạng xã hội → Card Collection / Medal Missions / tooltip Weekly Contest → thử lại mua.
  4. Thua: chỉnh giờ → hộp thư → DailyLogin → hoạt ảnh icon (thua) → tutorial Richards Journey → No Ads → tutorial Weekly Contest → tutorial Events tab → Card Collection → thử lại mua → auto-dialog.
  5. TryAddClaims theo thứ tự: Card Collection, Arena, Kingdom Pass, Pearls of Atlantis, Hidden Path, Coin Craze, Kingdom Duels, Island Race, Gem Hunt, Dungeon Escape, Power Rush, Flying Contest, Grand Tournament, Cube Blast, Magic Carnival, Emote Album, Team Adventure, Team Clash, Hill Quest, Canvas Quest, Weekly Mission, Richards Journey.
  6. TryAddAutoDialogs: hộp thư → Arena → Card Collection → Medal Missions → Kingdom Pass → Super Boost Offer → Dungeon Escape → Cube Blast → Magic Carnival → Emote Album → Super Electro Ball → Pearls of Atlantis → Hidden Path → Kingdom Duels → Island Race → Gem Hunt → Power Rush → Flying Contest → Grand Tournament → Team Adventure → Team Clash → Hill Quest → Canvas Quest → Weekly Mission → migrate Attack cũ → offer auto (Welcome Pack, Ladder Offer, Mythic Deal, Coin Craze) → nhắc nhở → mạng xã hội.
  7. TryAddStartDialogs: Kingdom Pass, Dungeon Escape, Cube Blast, Magic Carnival, Emote Album, Super Electro Ball, Pearls of Atlantis, Hidden Path, Blitz, Hill Quest, Canvas Quest, Weekly Mission, Richards Journey, Kingdom Duels, Island Race, Gem Hunt, Power Rush, Flying Contest, Grand Tournament, Team Adventure, Team Clash, Card Collection, Medal Missions.
