Mô tả

  • VersionManager so số build đang chạy (34771) với số build lưu lần trước để biết đây là cài mới, cùng bản, bản cập nhật hay bị hạ cấp.
  • Khi cập nhật, nó chạy chuỗi migrate dữ liệu theo từng mốc build cũ (xoá level tải từ xa, dọn bundle không dùng, chuyển khóa Arena / bạn bè / hồ sơ…).
  • Server gửi ForceUpdateVersion trong phản hồi Ping; nếu lớn hơn build hiện tại, client chờ về Home rồi hiện hộp thoại gốc của hệ điều hành 'Update is available!' chặn mọi chạm, chỉ có nút Update.
  • Bản bị hạ cấp hiện cảnh báo riêng.
  • AppManager đếm phiên, thời gian phiên, giờ cài đặt (máy và server) dùng cho nhiều tính năng khác; RegionHelper chặn chơi ở vùng bị cấm; AppConfig đặt FPS, tắt vSync và bật đa chạm chỉ ở Home.

Tóm tắt thiết kế

Code VersionManager so build đang chạy (34771) với build lưu lần trước để biết đây là cài mới / cùng bản / cập nhật / hạ cấp. Khi cập nhật, client xoá level tải từ xa, dọn bundle không dùng, rồi chạy lần lượt 35 bước migrate theo mốc build cũ (8121 → 33198).

Code Bắt buộc cập nhật hoàn toàn do server quyết định: Ping trả ForceUpdateVersion lớn hơn build hiện tại thì client đợi người chơi về Home (không cắt ngang màn), tắt chạm và hiện hộp thoại gốc của hệ điều hành “Update is available!” chỉ có nút Update. Server hạ số này xuống thì hộp thoại tự đóng.

Code Không có “cập nhật mềm” (gợi ý không bắt buộc) trong client. Cài bản cũ hơn thì hiện cảnh báo và gửi app_downgraded, không migrate ngược. Cảnh báo cấm vùng (“not available in your region”) được ưu tiên hơn cảnh báo cập nhật.

Luồng người chơi từng bước

  1. Xác định trạng thái phiên bảnClientCodeLive 11/11
    Bind → TryUpdateVersion: chưa có khoá Version thì NewInstall (0); bằng thì Same (1); cũ < mới thì Update (2); cũ > mới thì Downgrade (3). Log “Version: {0} / {1} -> {2} / {3}”. Live: Version = 34771.
  2. Migrate dữ liệuClientCode
    Update: RemoteLevels.RemoveAll, RemoveAllUnusedBundles, rồi các bước “nếu build cũ < mốc”: đổi khoá leaderboard (17795), Arena (20191, 32702), đổi tên hồ sơ (22299), dọn dữ liệu Hidden Path (26790), Welcome Back (28313), TeamChatOn (30325)… RefreshProgressIfNecessary có thể đổi RefreshId để buộc tải lại tiến độ từ server.
  3. Ping mang ForceUpdateVersionServerCode
    UpdateForceVersion(v) lưu khoá ForceVersion. Khi đang ở trạng thái Downgrade thì không cho đổi (“force update version cannot be updated”).
  4. Hộp thoại bắt buộc cập nhậtGiao diệnCode
    Đang trong màn chơi thì log “Force update waiting for home”. Về Home thì CheckForceUpdate → ShowForceUpdate: DisableTouch, gọi NativeService.ShowAlertMessage(“Update is available!”, “A new version of Royal Kingdom is available!”, “Update”).
  5. Gỡ yêu cầu / hạ cấpClientCode
    ForceUpdateVersion ≤ build thì TryCloseForceAlert mở lại chạm. Hạ cấp: ShowDowngradedAlertMessage, gửi event app_downgraded.
  6. Thống kê phiênClientCodeLive 11/11
    AppManager đếm SessionCount, thời gian phiên / tạm dừng, giờ cài (máy và server), pin lúc pause. Các số này được ads, offer và hỗ trợ dùng lại. Live: SessionCount = 1. AppConfig tắt vSync và chỉ bật đa chạm ở Home (để zoom kingdom).

Mở khóa & điểm vào

Luôn bật. Bắt buộc cập nhật chỉ khi server gửi ForceUpdateVersion > build hiện tại (PingHttpCommand → VersionManager.UpdateForceVersion). Không thấy cơ chế cập nhật 'mềm' (soft update) riêng trong client; push có loại link 'update' (DeepLinkHelper.GetNotificationLinkType).

Điểm vào:

  • Mỗi lần mở app (VersionManager.Bind → TryUpdateVersion)
  • Phản hồi Ping có ForceUpdateVersion
  • Vào Home (OnAfterSceneContextsLoad → CheckForceUpdate)
  • Push loại 'update' (suy luận: mở store)

Cách hoạt động

  1. VersionManager.Bind đọc build hiện tại (int.TryParse → currentVersion), đọc khóa Version và ForceVersion ở DB App, xác định VersionState: NewInstall (0) nếu chưa có, Same (1), Update (2) nếu cũ < mới, Downgrade (3) nếu cũ > mới (hiện ShowDowngradedAlertMessage, gửi 'app_downgraded').
  2. Log 'Version: {0} / {1} -> {2} / {3}'.
  3. Khi Update, Migrate() chạy: RemoteLevels.RemoveAll, RoyalBundleHelper.RemoveAllUnusedBundles, rồi các bước theo mốc build cũ < 8121, 9153, 10175, 10571, 10987, 11425, 12423, 12762, 12969, 13572 (xoá bộ lọc từ xấu), 13968, 15169, 15621, 17010, 17504, 17795 (đổi khóa leaderboard), 18068, 19049, 20191 (Arena: TryMigrateLastSeenCups, xoá reward cũ), 20895, 22299 (UserProfileManager.MigrateOldName), 23513, 24310, 25946, 26790 (HiddenPathLocalData.DeleteObsoleteData), 27844, 28313 (WelcomeBackManager.TryMigrate), 28802, 29838, 30325 (TeamChatOn), 30545, 31287, 31719, 32702 (ArenaLocalData.RemoveServerData), 33198…; RefreshProgressIfNecessary có thể đặt lại RefreshId để buộc tải lại tiến trình.
  4. Bắt buộc cập nhật: Ping trả ForceUpdateVersion; UpdateForceVersion(v) lưu ForceVersion (không cho giảm khi đang Downgrade); nếu forceVersion > currentVersion, khi đang ở Game thì đợi ('Force update waiting for home'), ở Home thì ShowForceUpdate: tắt chạm (GameTouchListener.DisableTouch), gọi NativeService.ShowAlertMessage(ForceUpdateTitle, ForceUpdateMessage, ForceUpdateAction).
  5. Nếu đang có cảnh báo cấm vùng thì nhường.
  6. Khi server hạ ForceUpdateVersion xuống ≤ build, TryCloseForceAlert gỡ cảnh báo và mở lại chạm.
