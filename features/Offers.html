Mô tả

  • Khung chung cho mọi gói bán có thời hạn: lớp cơ sở AOfferEventManager<TConfig, TStep, …> (Welcome Pack, Mythic Deal, Coin Craze) và LadderOfferManager nhận config JSON từ server theo revenue segment, cho người chơi vào offer, hiện dialog tự động / icon Home / ô trong Shop / ô 'end-game offer' trong dialog hết lượt và hết mạng.
  • Mỗi bậc offer (AOfferStep: s, p, d, n, r) bán qua product id <tiền tố>.<p> (p = 0 là miễn phí).
  • OfferManager tự quản lý offer King's Favor (gói coin + Hammer bán trong dialog Extra Moves khi thiếu coin để Play On) và gom danh sách end-game offer.
  • Namespace Home.Ui.Dialogs.Offer có 94 file UI (CoinCraze 21, LadderOffer 35, MythicDeal 15, WelcomePack 16, KingsFavor 3, EndGameOffer 3, AOfferEventManager 1).

Tóm tắt thiết kế

Code Mọi gói bán có thời hạn dùng chung một khung: Welcome Pack, Mythic Deal, Coin Craze kế thừa AOfferEventManager, Ladder có manager riêng cùng kiểu. Server gửi config theo revenue segment; mỗi bậc AOfferStep = s số bậc, p giá (đuôi product id, 0 = miễn phí), d % giảm giá hiển thị, n tên rương/gift box, r phần thưởng. Segment được chép và khoá lúc vào offer (segment 0 bị ép thành 1).

Code Offer xuất hiện ở 3 chỗ: dialog tự động khi về Home (một lần), icon bên phải Home và ô Shop (Feature Dependency xếp chỗ), và ô cuối màn trong dialog hết lượt / hết mạng.

Code Luật ô cuối màn: offer chỉ được chen vào khi coin hiện có nhỏ hơn giá Play On và coin hiện có + coin trong gói đủ giá Play On (DoesOfferHaveEnoughCoinForEgoPackage). Nghĩa là mỗi ô là một “vé chơi tiếp”. Thứ tự: quảng cáo thêm lượt → Welcome Pack (30) → Coin Craze (40) → Mythic Deal (50) → King's Favor nếu chưa có offer event nào → pass event → Kingdom Pass.

Code King's Favor là offer cứng trong client cho level ≥ 100 và tài khoản cài ≥ 7 ngày: payer 4.000 coin + 3 Hammer ($6.99), non-payer 1.000 coin + 1 Hammer ($0.99). Mỗi lần hết lượt có 33% cơ hội hiện, chắc chắn hiện sau 3 lần trượt liên tiếp; ô có đồng hồ 1 phút. Từ dialog hết mạng thì gói được gắn thêm đầy mạng.

Code Một số gói mua từ dialog hết lượt còn cho luôn lượt Play On của màn này mà không trừ coin (HasFreeEgoExtraMoves: King's Favor non-payer, Kingdom Pass, Coin Craze, pass event, ô quảng cáo; text “+{0} moves for this level!”). King's Favor payer, Mythic Deal và Welcome Pack thì không — người chơi dùng coin vừa mua để Play On.

Luồng người chơi từng bước

  1. Nhận offer và segmentServerCodeLive 11/11
    Ping gửi GetOfferEventInfoHttpCommand (eventId, version config user/server, version segment); server trả event server + event của user + OfferEventSegmentInfo (userSegment, segmentVersion). Lưu vào bảng riêng mỗi offer. Live 11/11: Ladder segment 1 (v183), Mythic Deal segment 1 (v147), Welcome Pack event 4 config v5.
  2. Vào offerClientCode
    Đủ level, bundle tải xong, điều kiện riêng thoả → AOfferProgress.EnterEvent, chép revenue segment thành event segment. Welcome Pack và Mythic Deal có hạn riêng 2 ngày kể từ lúc vào (OfferDurationInMs), Ladder và Coin Craze theo ngày kết thúc của event.
  3. Dialog tự độngGiao diệnCode
    Lần đầu về Home sau khi vào offer: TryAddStartDialog → dialog của offer (trigger Auto 0). Analytics OfferOpen (trigger Auto 0 / Click 1 / Reminder 2 / Reopened 3 / DeepLink 4 / Shop 5).
  4. Icon Home và ô ShopGiao diệnCodeAPK
    Feature Dependency cột phải: No Ads 15, Kingdom Pass 25, Ladder 55, Coin Craze 65, Welcome Pack 73 / Mythic Deal 75 (chung một ô). Shop: No Ads 10, Kingdom Pass 20, Welcome Pack 30, Coin Craze 40, Mythic Deal 50.
  5. Bậc thành gói muaClientCode
    AOfferStep.CreateShopConfig: product = tiền tố + “.” + p (welcomepackoffer, offer, ladder, progressoffer); p = 0 → product miễn phí ladder.0; thưởng r thành InventoryPackage; d hiện thành nhãn −d%.
  6. Dialog hết lượt: gom ôGiao diệnCode
    GetAvailableEndGameOffers: ô quảng cáo thêm lượt (nếu config quảng cáo bật dạng ô) → các offer event theo nhóm ego → King's Favor chỉ khi chưa có offer event → pass event → Kingdom Pass. Nhiều ô thì trượt ngang (EndGameOfferSliderScrollController).
  7. Lọc theo coinClientCode
    Mỗi offer tự xét TryAddOffer: lấy giá Play On hiện tại; coin hiện có ≥ giá → không hiện (người chơi tự Play On được); coin hiện có + coin trong gói < giá → không hiện.
  8. King's FavorGiao diệnCode
    Không có offer event nào: ShouldShowKingsFavorRandomizedOffer random [0,1) > 0,33 → bỏ và tăng bộ đếm trượt; đủ 3 lần trượt thì chắc chắn hiện rồi đếm lại. Quyết định giữ nguyên trong cùng một dialog. Chọn gói theo IsPaidUser. Ô có đồng hồ 1 phút (EndGameOfferDurationInMs); hình đổi theo kingdom, dark level, Champions Arena.
  9. Dialog hết mạngGiao diệnCode
    Cùng hàm với isMoreLivesDialog = true: offer event chỉ hiện khi đã hết mạng; King's Favor được gắn RefillLives (“Free life refill!”), không chạy đồng hồ 1 phút.
  10. MuaNgười chơiCode
    OfferManager.OnPurchaseSuccess → tìm manager của gói (TryGetManagerOfPackage) → đánh dấu đã mua, gửi OfferClaim (type, step, giá, package, transactionId). Gói có lượt Play On miễn phí: token +N lượt bay vào và màn tiếp tục không trừ coin.
  11. Hết hạn hoặc bị tắtClientCode
    Hết hạn → EventTimeFinished, gỡ icon và ô Shop. Server tắt (cờ disabled) → ResetData. Ladder: server lùi ngày kết thúc → xoá dữ liệu.

  • Chỉ bán ở dialog hết lượt khi gói vừa đủ cứu màn: không làm phiền người đủ coin, và mỗi ô offer có lý do mua rõ ràng ngay lúc đó.

Mở khóa & điểm vào

King's Favor: level ≥ 100 (KingsFavorUnlockLevel = 100, get_HasEnoughLevelForKingsFavor: Level > 99) và ≥ 7 ngày từ lúc cài (server install time, RequiredInstallTimeDurationInMs = DaysInMs(7)). Offer event: theo UnlockLevel của từng manager (Welcome Pack 13, Ladder 35, Mythic Deal 100) + server gửi event + Feature Dependency.

Điểm vào:

  • Ô offer trong dialog Extra Moves (hết lượt) — EndGameOfferViewController / EndGameOfferSliderScrollController
  • Ô offer trong dialog hết mạng (More Lives)
  • Dialog tự động khi về Home (TryAddStartDialog → CreateStartDialogAction)
  • Icon bên phải Home (Feature Dependency nhóm right)
  • Ô special trong Shop (nhóm shop)
  • Deeplink (OfferOpenTrigger DeepLink = 4; Ladder: ladderoffer)

Cách hoạt động

  1. Mỗi offer event là một AEventManager: server trả OfferEventResponseContent gồm thông tin event server (eventId, configVersion, config, endDate), event của user và OfferEventSegmentInfo (userSegment, segmentVersion).
  2. Manager lưu vào bảng riêng (LadderOfferTableItem, MythicDealTableItem, WelcomePackTableItem: EventId, EventEndDate, EventConfig, EventConfigVersion, RevenueSegment, RevenueSegmentVersion), parse config bằng ParseConfig(configText, segmentIndex) — mỗi config là mảng theo segment.
  3. Khi đủ điều kiện (CanEnterEvent, IsEventEligible, level, bundle tải xong) manager vào event: ghi EventId và sao chép revenue segment hiện tại sang event segment (AOfferProgress.CopyUserSegmentToEventSegment, segment 0 bị ép thành 1), đặt hạn riêng nếu có OfferDurationInMs (Welcome Pack, Mythic Deal: 2 ngày).
  4. Bậc hiện tại (TryGetCurrentStepInfo) được biến thành ShopPackageConfig (AOfferStep.CreateShopConfig: product = tiền tố + '.' + p, gói = r, kiểu ô và EndGameOfferType theo lớp con).
  5. Offer xuất hiện ở 3 chỗ: dialog tự động (một lần, CanShowAutoPopup), icon/Shop (Feature Dependency sắp xếp ưu tiên), và end-game offer: OfferManager.GetAvailableEndGameOffers gom theo thứ tự: quảng cáo thêm lượt (AdManager.TryAddOffer), offer event nhóm ego (Welcome Pack 30, Coin Craze 40, Mythic Deal 50), King's Favor nếu chưa có gì, event pass, rồi Kingdom Pass.
  6. Mỗi offer event chỉ được đưa vào end-game khi coin hiện có < giá Play On và coin của offer + coin hiện có ≥ giá Play On (DoesOfferHaveEnoughCoinForEgoPackage).
  7. Mua thành công → manager của gói (AOfferEventManager.TryGetManagerOfPackage) nhận OnPurchaseSuccess, đánh dấu IsOfferPurchased, gửi OfferClaim; hết hạn → EventTimeFinished.
